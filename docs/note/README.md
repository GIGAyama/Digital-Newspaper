## 貼る前に直すところ

**連載番号が `#◯` のままです。** 1行目のタイトルの `#◯` を実際の号数に置きかえてください。
過去の記事が手もとに無く、推測で埋めると連載が壊れるので空けてあります。

前作との地続きを作りたい場合は、「🏫 はじめに」の GitHub の URL のあとに
一文足すのがいちばん収まります。過去の記事を読めていないので、
「以前紹介した◯◯と違って」といった書き出しはこちらでは書いていません。
いまは「URL を配ればすぐ使える形ではない」という、このアプリ自身の性質だけを書いてあります。

## note に貼る手順

1. note の新規投稿を開き、記事の1行目（タイトル欄）に `#` を外した見出しを入れる
2. 本文を `## 🏫 はじめに` 以降から貼る。note は `##` を見出しとして受け取り、目次を自動で作る
3. `![...](images/xx.png)` の行は貼っても画像になりません。**その位置で画像を手動アップロードし、Markdown の行は消す**
4. 画像の直後の一文は、note の**キャプション欄**に移す。本文に残すと二重になります
5. 太字・表・記号は使っていないので、貼り付け後の手直しは要りません
6. ハッシュタグの候補は `#GIGAスクール` `#学級新聞` `#GoogleAppsScript` `#小学校` `#校務効率化` `#ICT教育`

見出しは 8 本です。目次はこの並びで出ます。

```
🏫 はじめに
📱 このアプリでできること
🗞️ 縦書きの紙面が、その場で組み上がる
🔗 紙にのせられなかったものは、QRコードで
✨ 導入のメリット
🛠️ 【管理者向け】導入手順
📖 【利用者向け】使い方のガイド
📝 まとめ
```

`🗞️` と `🔗` の2本は、文体ガイドの「目玉が既存の見出しに収まらないときだけ
📱 と ✨ のあいだに2本まで足す」に沿って足したものです。

## 撮影について、書き手が知っておくべきこと

**画面はすべて本物です。`post.html` と `admin.html` をそのままブラウザで開いて、
文字を打ち、ボタンを押して撮りました。合成も加工もしていません。**
児童が1本投稿し、その投稿が編集室に現れ、それを含めて紙面を組む、という順で通しています。

そのうえで、次の3つは撮影のために用意したものです。記事の中でも
「実際の教室での出来事」としては一切書いていません。

1. **記事の中身は見本です。** 三年二組の8本の記事と児童名は、撮影のために書いたもので、
   実在の学級のものではありません
2. **写真は挿絵です。** 児童の顔が写った本物の写真は使えないので、
   運動会のグラウンド、ミニトマト、ドッジボール、なわとび、プールの
   5点を絵で用意しました（`capture/assets/`）
3. **サーバー側は手もとの代役です。** 本番の `script.google.com` へは
   作業環境から到達できないため、`Code.gs` と同じ入出力を持つ小さなサーバを立てて撮りました
   （`capture/gas-server.mjs`。AUDIT.md の計測と同じやり方です）。
   画面の HTML には手を入れていません。書きかえたのは次の3点だけです。
   - `<?= ScriptApp.getService().getUrl() ?>` を `/exec` に畳む（GAS がやることの代わり）
   - unpkg と Google Fonts の URL を、npm から取った同じ版のローカル写しに向ける
   - `google.script.run` を、同じ形で手もとのサーバを呼ぶものに差しかえる

**QR コードは本物です。** 記事に写っている QR は、実際に `qr-creator` が描いたもので、
塗られた画素は 5,017 でした（空の四角なら 0 になります）。
リンク先の Google ドライブの URL は見本の文字列です。

## 撮り直すときの手順

`capture/` に道具一式が入っています。リポジトリの根で次を実行してください。

```bash
npm i --no-save playwright @picocss/pico@1.5.10 \
  @fontsource/shippori-mincho @fontsource/noto-sans-jp \
  @fontsource/yomogi @fontsource/kiwi-maru @fontsource/biz-udpgothic

node docs/note/capture/gas-server.mjs 4180 &

LANG=ja_JP.UTF-8 LANGUAGE=ja \
  node <note-article スキル>/scripts/capture.mjs docs/note/capture/shots.mjs \
  --base http://127.0.0.1:4180/exec --out docs/note/images
```

`LANGUAGE=ja` を落とさないでください。落とすとブラウザの部品が英語になり、
写真を選ぶボタンが「Choose File」に、日付の絞りこみが「mm/dd/yyyy」になります。
日本語の記事の画像としては具合が悪いところです。

Pico.css と日本語フォントを npm から入れているのは、この作業環境から
unpkg と Google Fonts に出られないためです。同じ版の実バイトを手もとに置いて配っています。
出られる環境なら、この2つは入れなくても同じ画面になります。

`shots.mjs` は上から順に通すシナリオです。画面ごとの寸法は次のとおりです。

- 児童の画面 … 幅 390。全体を1枚に収めるところだけ縦 1800
- 編集室の操作パネル … 1440×1250
- 記事一覧だけを見せる画面 … 620×1200。この幅では列が縦に積まれる
- 紙面 … 1000×1260。A4 縦のおおよそ 794×1123px が1枚に収まる

`capture/` を消してしまうと撮り直せません。本来この手のシナリオは納品前に消すものですが、
このアプリはビルド成果物を持たない Google Apps Script なので、
代役のサーバが無いとブラウザで開くことすらできません。だから残してあります。

## 文体について踏襲したこと

連載の書き手の執筆プロンプトに合わせて、次を守っています。

- 太字を使っていません（実測 0）
- 表・斜体を使っていません（実測 0）
- `→` `／` `：` `▲` `▶` を使っていません（実測すべて 0）
- 箇条書きは手順のときだけです。導入手順と使い方のガイドの中だけに置いています
- 絵文字は見出しだけです。本文には入れていません
- 「関数」「ローカルストレージ」といった言葉を出さず、
  「公開するときの設定」「その端末のブラウザの中にしかありません」と言いかえています。
  「デプロイ」だけは導入手順に残しています。Apps Script の画面に出ているボタンの名前そのもので、
  言いかえると押すところが分からなくなるためです。すぐあとに「ここが公開の設定です」と添えてあります
- 子どものことは「子どもたち」、読み手は「先生」「先生方」、です・ます調
- 本文の字数は 7,267 字です（画像の記法を除いた数）

そして、**教室での出来事を実体験としては書いていません。**
これは作者の実践記録ではないので、「使ってみたら子どもたちが」とは書けません。
書いてあるのは「こうなればいいと思って作った」「〜だと思います」までです。
実際の授業での様子は、書き手が自分で足すところとして空けてあります。

同じ理由で、効果も言い切っていません。「放課後が返ってくる」「書く子が増える」は
見立てとして書いてあり、「〜と思います」で受けています。
