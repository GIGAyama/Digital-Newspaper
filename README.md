# 📰 デジタル・クラス新聞社

児童がタブレットから記事を投稿し、先生がそれを選んで並べ、**A4 の学級新聞として印刷（または PDF 保存）する**ための Google Apps Script（GAS）ウェブアプリです。

Google スプレッドシートをデータベース、Google ドライブを画像置き場として使います。サーバーの用意やインストールは要りません。

操作手順は **[MANUAL.md](MANUAL.md)** に、アクセシビリティの点検記録は **[AUDIT.md](AUDIT.md)** にあります。

---

## このアプリでできること

### 児童（記者ページ / `index.html`）

- タイトル・本文・記者名・タグ・写真（1枚）を送って記事を投稿する
- 漢字にふりがな（ruby）が付いた画面で操作する
- タグは先生が設定したものから 1 つ選ぶ（選択は必須）
- 送信に失敗しても、自動で最大 3 回まで再送を試みる

投稿できるのは**新規の記事だけ**です。児童が自分の記事をあとから直したり消したりする画面はありません。

### 先生（新聞編集室 / `admin.html`）

- 投稿された記事を一覧で見て、**チェックを入れたものだけ**を紙面に載せる
- キーワード（タイトル・記者名）／タグ／投稿日の範囲で絞り込む
- ドラッグ＆ドロップで掲載順を並べ替える
- 紙面の上で、新聞名・発行日・見出し・記者名・本文を**直接書き換える**
- 用紙の向き（A4 縦／横）、縦書き／横書き、段組み（1〜4段）、文字サイズ（8〜24px）を変える
- テーマ 7 種・フォント 5 種・見出しスタイル 6 種から選ぶ
- 記事ごとに写真の位置・大きさ・形を変える／見出しを隠す
- 記事に URL を紐づけて、紙面に **QR コード**を刷り込む（動画などへの導線）
- 「編集後記」のような、投稿によらない**自由記述欄**を足す
- 編集途中の状態に名前を付けて保存し、あとから呼び出す
- レイアウトとデザインだけを**テンプレート**として保存し、別の号に適用する
- 児童画面に出すタグ（絵文字・名前・ふりがな）を編集する
- ブラウザの印刷機能で A4 に印刷、または PDF として保存する

## 構成

| ファイル | 役割 |
|---|---|
| `Code.gs` | サーバー側。スプレッドシート／ドライブの読み書き、スプレッドシートのメニュー、`doGet` |
| `index.html` | 児童用の投稿ページ |
| `admin.html` | 先生用の編集室（紙面プレビューと印刷） |
| `AUDIT.md` | 点検の記録（実測値と、測っていないものの明示） |
| `MANUAL.md` | 操作マニュアル |
| `scripts/check-project.mjs` | 品質ゲート。静的に読めば分かることを検査する |
| `tests/check-project.test.mjs` | 品質ゲートそのものを、わざと壊して確かめるテスト |
| `.github/workflows/ci.yml` | CI。`pull_request` と `push` の両方で上の2つを回す |

### 画面の切り替え

`doGet(e)` が `p` パラメータだけを見ます。

| URL | 表示 |
|---|---|
| `https://script.google.com/.../exec` | 記者ページ（`index.html`） |
| `https://script.google.com/.../exec?p=admin` | 新聞編集室（`admin.html`） |

**編集室に入るための合言葉やパスワードはありません。** 誰が入れるかは、デプロイ時の「アクセスできるユーザー」の設定だけで決まります。記者ページの下部にも編集ページへのリンクが置かれているので、児童からも編集室の場所は見える状態です。校内で限定公開にするなど、公開範囲の設計は運用側で行ってください。

### データの置き場所

同じスプレッドシートの中に、2 つのシートが自動で作られます。

**`Articles` シート**（記事本体。初回投稿時に自動生成）

| 列 | 内容 |
|---|---|
| `ID` | UUID（`Utilities.getUuid()`） |
| `Title` | 記事のタイトル |
| `Body` | 本文 |
| `ImageURL` | 画像の URL（`https://lh3.googleusercontent.com/d/<ファイルID>`）。写真なしの場合は空 |
| `Reporter` | 記者名 |
| `Timestamp` | 投稿日時 |
| `Status` | 常に `Pending` が書き込まれます（後述） |
| `Tag` | 選ばれたタグ名 |

列は**ヘッダー名で探し**、見つからなければ上の並び順にフォールバックします。列を入れ替えてもヘッダー名が合っていれば動きます。

**`SystemData` シート**（設定の保存先。非表示シートとして自動生成）

`Type` / `Name` / `Data` / `Date` の 4 列。`Type` は `LAYOUT`（一時保存）か `TEMPLATE`（デザインテンプレート）のどちらかです。

**スクリプトプロパティ**

| キー | 内容 |
|---|---|
| `IMAGE_FOLDER_ID` | 写真の保存先ドライブフォルダの ID |
| `TAG_SETTINGS` | タグ設定の JSON。未設定なら既定の 5 タグ（ニュース／行事／学習／遊び／その他）が使われます |

## セットアップ

1. Google スプレッドシートを新規作成する
2. **拡張機能 → Apps Script** を開く
3. 次の 3 つのファイルを作る。**ファイル名は完全に一致させてください**（`Code.gs` が `index` / `admin` という名前で HTML を読み込みます）
   - `Code.gs` … スクリプトファイル
   - `index.html` … HTML ファイル（Apps Script 上の名前は `index`）
   - `admin.html` … HTML ファイル（Apps Script 上の名前は `admin`）
4. **デプロイ → 新しいデプロイ → ウェブアプリ**
   - 「次のユーザーとして実行」: **自分**
   - 「アクセスできるユーザー」: 運用方針に合わせて選ぶ（校内ドメイン内など）
5. スプレッドシートを再読み込みすると、**📰 新聞システム** メニューが出ます
   - **1. 写真フォルダの設定** … 写真を貯めるドライブフォルダの ID を入れる。設定しないまま最初の写真が届くと、`新聞システム画像フォルダ` という名前のフォルダが自動で作られ、その ID が記録されます
   - **2. 先生用管理画面を開く** … 編集室と投稿画面の URL がダイアログで出ます

デプロイ前に「2. 先生用管理画面を開く」を実行すると、URL が取れない旨の警告が出ます。先にデプロイしてください。

### 写真の公開範囲について（要確認）

投稿された写真は、紙面プレビューに表示するために **「リンクを知っている全員が閲覧可」** に設定されてドライブへ保存されます（`Code.gs` の `file.setSharing(...)`）。URL が漏れれば校外からも見えます。児童の写真を扱う以上、ここは導入前に必ず確認してください。

## 実装上の注意（できないこと・気をつけること）

ドキュメントと実装がずれないよう、**現時点で実装されていないこと**を明記します。

- **承認フローはありません。** `Status` 列には `Pending` が書き込まれますが、この値をどこかで読んだり書き換えたりする処理は存在しません。編集室には投稿された記事がすべて出ます。「掲載する／しない」はチェックボックスの選択だけで決まります。
- **紙面は 1 ページ分だけです。** A4 の枠は `overflow: hidden` で、はみ出した記事は画面にも印刷にも出ません。段数・文字サイズ・写真の大きさで収めてください。
- **紙面上で直した文章は、スプレッドシートに戻りません。** 見出し・記者名・本文の書き換えはブラウザ内に持つだけです。「一時保存」しておかないと、再読み込みで消えます（記事一覧のタグ欄だけは例外で、直した瞬間にスプレッドシートへ書き戻されます）。
- **記事を削除する機能はありません。** 消せるのは、その場で足した自由記述欄だけです。投稿記事を消すにはスプレッドシートの行を直接消します。
- **「一時保存」は同じ名前でも上書きせず追記します。** 呼び出すと最新のものが復元されますが、一覧には同名の項目が並びます。（「テンプレート」は同名を上書きします。）
- **キーワード検索は本文を対象にしません。** タイトルと記者名だけを見ます。
- **絞り込み中も自由記述欄は常に表示されます。** タグ・日付の条件は投稿記事にだけ効きます。
- **タグ設定を変えても、投稿済みの記事のタグ文字列は変わりません。** 記事には選択時のタグ名が文字列として残ります。
- **QR コードにできるのは `http` で始まる URL だけです。**
- **オフラインでは動きません。** PWA 化していないため、`script.google.com` に接続できないと開けません（→ [AUDIT.md](AUDIT.md)）。ただし**学校のフィルタリングで CDN が塞がれても動きます**（下記）。
- `index.html` の `.full-viewport`（`100dvh`）は CSS に定義されているだけで、現在どの要素にも付いていません。

### 同時アクセス

同じ時刻に複数の児童が送信してもデータが壊れないよう、書き込みには排他ロックをかけています（記事の保存は最大 10 秒待ち、タグの更新は最大 5 秒待ち）。待っても取れなかった場合は児童の画面にエラーが出て、自動で再送を試みます。

## 使っている外部リソース

学校のネットワークは `unpkg.com` や `fonts.googleapis.com` を塞いでいることがあります。
**塞がれても動くもの（見た目だけ）に限って、外部から読んでいます。**

| 用途 | 読み込み先 | 塞がれると |
|---|---|---|
| CSS フレームワーク（記者ページ） | Pico.css 1.5.10（unpkg） | 字と余白が変わるだけ。入力も送信もできる（実測） |
| フォント | Google Fonts | 端末側のフォントに落ちるだけ |
| QR コード生成（編集室） | **同梱**（qr-creator 1.0.0 / MIT） | — |

QR は以前 cdnjs から読んでいましたが、塞がれると `<canvas>` だけが残り、
**読み取れない白い四角が紙面に刷られていました**（実測：塗られた画素 2500 → 0）。
アプリ全体は動くので気づけません。いまは `admin.html` に同梱してあり、
**CDN から取る実行コードは 0 バイト**です。

同梱ライブラリを更新する手順は `admin.html` の該当コメントに書いてあります。

## 開発

```bash
node scripts/check-project.mjs           # 品質ゲート
node scripts/check-project.mjs --list    # 検査項目の一覧
node --test tests/check-project.test.mjs # 検査そのものを確かめる
```

CI が `pull_request` と `push` の両方でこの2つを回します。
**検査を直したら、わざと壊した入力で確かめるテストも一緒に直してください。**
「0件でした」だけでは、検査が動いているのか何も見ていないのか区別できません。
